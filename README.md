# MySQL Interview Revision

Concise MySQL revision for a full-stack developer with 2 years of overall development experience and working MySQL knowledge preparing for interviews in India. Not a database-specialist track. Focus: common interview questions, query writing, basic design/indexing, transactions, and application scenarios. Baseline: MySQL 8.4 LTS with InnoDB.

## Start Here

1. Review [SYLLABUS.md](SYLLABUS.md): one interview-priority list of 24 topics, no phases. Common SQL questions come first; specialist topics are optional.
2. Review [start.md](start.md): topic index, filenames, and progress.
3. Start with the joins note and exercises linked from the index. All 24 registered topic pairs are available; use [progress.html](progress.html) for the interactive checklist.

## Content Format

- Each topic will have a concise note and a separate exercise file, both inside `notes/` and linked from `start.md`.
- Answers are written to be spoken directly in an interview, with short explanations and correct MySQL examples.
- Each exercise file contains 10-15 answered questions, default 12, including scenario-based queries or production/design tasks, sample data where relevant, and expected results.
- Difficulty is mainly quick-to-medium, with at most 2 optional stretch questions per file. Follow the displayed topic order, not numerical IDs.
- Attempt questions before reading answers. Mark a topic Revised only after explaining it and solving a representative scenario unaided.

- [CLAUDE.md](CLAUDE.md) and [.github/copilot-instructions.md](.github/copilot-instructions.md) define coaching, content, safety, and validation rules.
